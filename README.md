# Эстафета

Система для дипломной работы: **LLM как инструмент борьбы с потерей знаний при увольнении**.  
По документам уходящего сотрудника собирается база знаний для преемника.

## Что умеет

1. Карточка эстафеты: сотрудник, роль, преемник, дата ухода.
2. Загрузка PDF, DOCX, TXT, Markdown. Секреты (пароли, ключи) вычищаются.
3. Нарезка текста и поиск BM25 по фрагментам.
4. Извлечение карточек: обязанности, процессы, люди, системы, долги, решения, FAQ, глоссарий, риски.
5. Диалог преемника с базой и выгрузка `playbook.md`.

Без `LLM_API_KEY` система уже работает: индекс, эвристические карточки, ответы цитатами.  
С ключом OpenAI-совместимого API карточки и ответы формулирует модель.

## Запуск

Нужен Python 3.11+.

```powershell
cd C:\Users\Asus\Projects\knowledge_base_handoff
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
python -m app
```

Откройте http://127.0.0.1:8000 и нажмите **«Демо: платёжный контур»**.

В `.env` можно указать:

```
LLM_API_KEY=...
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini
```

Подойдут OpenRouter, Groq и Ollama (`LLM_BASE_URL=http://127.0.0.1:11434/v1`).

## Архитектура

- `app/ingest.py` — разбор файлов и чанки
- `app/extract.py` — LLM или эвристики → карточки знаний
- `app/retrieve.py` — BM25 + ответ модели с цитатами
- `app/main.py` — FastAPI и статическая витрина `web/`
- SQLite в `data/estafeta.db`

Демо-документы лежат в `sample_docs/` (вымышленный платёжный контур, без реальных секретов).
