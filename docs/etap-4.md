# Этап 4 — журнал аудита

## Реализовано

- Alembic-миграция `0004_audit` создаёт append-only таблицу `audit_events`:
  идентификатор с последовательностью, время, тип события, ID и роль актёра,
  тип/ID объекта, ограниченные JSON-метаданные.
- В журнал не записываются пароли, токены, содержимое материалов/вопросов,
  адреса электронной почты, тексты ошибок, IP-адреса или другие поля из
  пользовательского ввода. Типы объектов и метаданные ограничены перечнями в
  приложении и CHECK-ограничениями БД. Метаданные допускают только счётчик
  CSV-импорта и роль создаваемой учётки для соответствующих типов событий;
  размер JSON ограничен в БД.
- Для приложения RLS разрешает чтение только роли `security_auditor`.
  Вставка разрешена для текущего актёра (или анонимного события входа).
  PostgreSQL-триггеры запрещают UPDATE, DELETE и TRUNCATE, в том числе владельцу
  таблицы. Приложение работает отдельной ролью `estafeta_app`.
- Журналируются успешные и неуспешные входы, выход, принятие приглашения,
  начало/результат настройки TOTP, создание учётной записи, CSV-импорт,
  восстановление, разблокировка и создание первого администратора.
- События добавляются в ту же транзакцию, что и соответствующее действие:
  сбой записи аудита откатывает операцию, не создавая ложного впечатления, что
  действие зарегистрировано.

## API чтения

`GET /api/audit/events` — доступен только вошедшему пользователю с ролью
«Аудитор ИБ». PostgreSQL RLS независимо ограничивает чтение той же ролью.

Поддерживаются фильтры `event_type`, `actor_user_id`, `since`, `until`, курсор
`before_id` и `limit` от 1 до 100 (по умолчанию 50). Даты должны включать
часовой пояс. Ответ содержит `items` и `next_before_id`; события упорядочены
по убыванию монотонного ID.

## Проверки и границы

Локальные unit/API-тесты проверяют безопасную схему метаданных, фильтры,
пагинацию и запрет доступа не-аудиторам. PostgreSQL-интеграционный тест проверяет
RLS, корректную вставку от имени актёра и запрет мутаций.

Доступ к API чтения проверяется по роли. Загрузка, публикация, просмотр чужих
пространств, экспорт, вопросы к ИИ и действия эстафеты будут подключать запись
событий в этапах, где появятся эти действия. Физическое архивирование старше
года не включено: журнал не удаляется автоматически и хранится дольше
обязательного годового срока.
