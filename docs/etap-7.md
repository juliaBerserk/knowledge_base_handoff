# Этап 7 — публикация, проверка и копирование

Миграция `0007_publication` добавляет общую настройку обязательной проверки и
поля происхождения копии. По умолчанию проверка включена. Администратор меняет
настройку через отдельное подключение к PostgreSQL с ролью `estafeta_admin`.

- Сотрудник отправляет личный черновик на проверку. Руководитель его отдела
  видит только отправленный объект и может опубликовать его или вернуть
  в черновики. При отключённой проверке автор может опубликовать свой
  черновик напрямую. Уже отправленные объекты остаются в очереди руководителя.
  При обязательной проверке руководитель не может одобрить собственный черновик.
- При публикации объект переходит в пространство должности владельца.
  Идентификатор и автор остаются прежними. При разборе личного пространства
  уходящего руководитель может опубликовать материал для последней должности
  сотрудника в отделе разбора. Открытие самого разбора входит в этап эстафеты.
- Автор может архивировать личный черновик. Публикации архивирует руководитель
  отдела соответствующей должности. Архивные публикации исключаются из выдачи.
- Публикации коллег доступны через фильтр автора в области должности или
  отдела. Сотрудник может скопировать доступную опубликованную запись.
  Копия — самостоятельный личный черновик с текстом на момент копирования,
  идентификатором оригинала и идентификатором его автора. Архивирование
  оригинала не удаляет копию.

Изменения состояния и копирование проходят в одной транзакции с записью
в аудит. Прямой UPDATE объектов прикладной роли не выдан. БД повторно
проверяет условия перехода в функции под блокировкой объекта.

## API

- `GET /api/publication/{kind}` — список, по 50 объектов. Поддерживает
  `scope=personal|review|position|department`, `after_id` и фильтр
  `author_id` для публикаций.
- `GET /api/publication/{kind}/{id}` — открыть доступный объект.
- `POST /api/publication/{kind}/{id}/{operation}` — `submit`, `return`,
  `publish`, `archive` или `copy`. Копирование доступно для `records`.
- `GET /api/settings/publication` и `POST /api/settings/publication` —
  прочитать или изменить настройку `review_required`.

`kind` принимает значения `materials` и `records`. POST-запросы требуют
JSON и действительный `X-CSRF-Token`. Запуск через `docker compose up --build`
применяет миграцию. Новых переменных окружения нет.
